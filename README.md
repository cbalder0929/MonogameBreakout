# MonoGame Breakout

A published Windows x64 build of the Breakout game.

## Run

Download this repository as a ZIP and extract it, then double-click `BreakoutStep1.exe`.
Keep the executable, DLLs, JSON files, language folders, and `Content` folder together.
The .NET runtime is bundled with the game.

From PowerShell in this folder:

```powershell
.\BreakoutStep1.exe
```

This repository contains the published game files. The original C# source projects are not included.
